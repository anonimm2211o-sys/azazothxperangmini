# AzazothX — UI Prototype

A dark, compact Roblox Lua UI prototype focused on readable layout and mobile-friendly controls.

## Current scope

- Dark charcoal theme with muted green accents
- Compact panel layout
- Minimize and restore controls
- Draggable header
- Auto Collect / Auto Sell **UI state toggles only**
- Activity log for UI status messages

> The toggles are placeholders. This repository does not implement automation, exploit calls, hidden remotes, or interactions with a third-party game's systems.
